# Burn N’ Learn 🍎🔥

**Burn N’ Learn** is a health and fitness iOS app designed to help users track daily calorie intake and health metrics. It combines motivational content, nutrition tracking, and integration with HealthKit to make fitness engaging and sustainable.

---

## 👥 Team Members
- **Myat Phone Paye** (6530258)  
- **Thant Zin Min** (6611968)

---

## 📖 Overview
Staying consistent in tracking calories and maintaining motivation is a common challenge for health-conscious individuals.  
**Burn N’ Learn** addresses this by providing:
- A home dashboard with daily statistics  
- Nutrition input tracking (breakfast, lunch, dinner)  
- A fitness video collection with search functionality  
- Motivational notifications to encourage healthy habits  

---

## 🎯 Target Users
- Fitness enthusiasts  
- Health-conscious individuals  
- Anyone who wants to monitor dietary habits and physical activity  

---

## 🛠️ Technologies Used
- **UIKit Components**
  - `UINavigationController`, `UITabBarController`, modal navigation
  - `UITableView`, `UICollectionView`
- **Data & API**
  - [Alamofire](https://github.com/Alamofire/Alamofire) for API requests
  - `UserDefaults` for persistence
  - **HealthKit** for health data
- **Authentication**
  - Firebase (Login & Signup)
- **UI/UX Enhancements**
  - Custom fonts
  - Local (in-app) notifications
  - Image / Camera Picker
  - DGCharts for nutrition data visualization
  - Music & video playback
  - TextField validation (name must start with uppercase letter)

---

## 📱 App Features
### 🔑 Login & Sign Up
- Secure authentication with **Firebase**

### 🏠 Home Page
- Health data integrated with **HealthKit**  

### 🍽 Nutrition Page
- Input meals (Breakfast / Lunch / Dinner)  
- Display user nutrition breakdown with **DGCharts**

### 🎥 Video Page
- Fitness & motivation video collection  
- Search functionality with **UICollectionView**

### 👤 Profile Page
- Edit profile with **Image/Camera picker**  
- TextField validation for names  

---

## 🚀 For Uplift
- Third-party libraries via **Swift Package Manager (SPM)**  
- Local notifications (4 times daily)  
- Clean architecture with **MVVM pattern**

---

## ⚡ Problems & Solutions
- **HealthKit Integration** → Overcame challenges with Apple docs & guidance  
- **Notifications** → Implemented scheduled reminders 4x/day  
- **API Data Fetching** → Handled using Alamofire & MVVM  
- **Architecture** → Applied MVVM clean framework for better scalability  

---

## ✅ Conclusion
**Burn N’ Learn** helps track calories, water intake, and activity while motivating users to stay consistent.  
The app provides a **user-friendly design** and encourages sustainable fitness habits.
